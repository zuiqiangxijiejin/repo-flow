# 可选功能

从设置 → 可选功能进入能力目录。可以搜索工具集成、技能和扩展，查看说明、状态、依赖和配置入口。默认工作区侧栏仍聚焦仓库与对话。

## 用户可以自行配置什么

- 在可用的工具集成中查看并配置账号被授权使用的连接。
- 在技能目录中查看或导入 `.skill` 技能文件，按已有界面管理启用状态；共享技能安装需要管理员权限。
- 使用“导入智能体”进入自定义 Agent 管理页，导入 JSON 配置包。子智能体在设置的独立页面新增与编辑，目前没有单独的文件导入按钮。
- 查看已加载扩展的页面、说明和可用配置。
- 在设置 → 连接管理自己的 GitHub，在 SSH 连接中管理自己的远程主机。
- 在设置中打开记忆、通知和 IM 渠道配置；实际可用范围取决于服务器部署和当前授权。
- 从可选功能中的“定时任务”和“Token 用量”打开相应页面，主侧栏继续保留仓库与对话。
- 在设置 → 外观开启“高级输入工具”，在当前设备显示引用、语音和润色按钮。默认关闭；不会替用户开启服务器能力。

目录中可见并不代表已经安装、已经启用、已经配置凭据或已经完成授权。这些状态分别展示。操作是否出现及是否可执行由当前权限决定。

## 需要维护者处理什么

安装会在 Gateway 中执行 Python 代码的扩展、调整全局 MCP 配置，以及开启服务级的记忆、定时任务、渠道或后台 worker，仍由维护者控制。普通用户的前端设置不能开启服务器没有加载的能力。

精简部署使用 `REPOFLOW_PROFILE=workspace`；完整部署和各功能开关以实际配置为准。保留的可选能力包括记忆、项目、知识检索、定时任务、IM 渠道、浏览器控制与子智能体等，它们的主题说明位于[文档目录](../README.md)。

开发扩展参阅[扩展契约](../full-stack-plugins.md)和[扩展示例](../../examples/README.md)。维护者安装或升级代码扩展后需重启 Gateway；仅在目录里看到某个扩展不会触发安装。
