# Why RepoFlow

RepoFlow connects an Agent conversation to a repository workspace while keeping code review, verification and contribution publishing visible to the user.

Associate a repository or fork, work in an isolated conversation workspace, inspect actual tool activity and test output, then confirm pushing and PR creation separately. Saving PR information locally, pushing a fork and creating a GitHub draft or ready-for-review PR are distinct actions.

Keep the workspace compact and configure optional tools, skills and extensions from Settings. Account permissions and server capabilities determine availability.
