# 第一次对话

先按[快速开始](/docs/application/quick-start)启动应用并登录，确认有可用模型。默认入口为 `http://localhost:2026`，服务器部署以实际地址为准。

1. 点击 **新对话**，选择自己的项目或 Fork。上游仅在向其他项目贡献时填写。
2. 选择模型与模式，先发送：

```text
请介绍这个仓库的结构、测试命令和贡献流程，先不要修改文件。
```

3. 展开执行记录查看实际工具调用，核对回答引用的文件。
4. 准备好任务后，再说明要修改的问题与验证要求。
5. 完成后打开 Git 审阅，检查差异和测试结果，再分别决定推送与创建 PR。

模型只能调用当前已启用且有权限使用的工具；执行结束并不自动代表验证成功。

继续阅读[工作区使用](/docs/application/workspace-usage)与[工具和技能](/docs/tutorials/use-tools-and-skills)。
