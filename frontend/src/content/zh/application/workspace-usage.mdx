# 工作区使用

左侧深色导航栏保留新对话、GitHub 仓库、最近对话和设置。收起后可从图标栏使用常用入口，悬停可查看说明。仓库扩展加载后，SSH、仓库配置和克隆管理也可直接打开。

## 对话与模型

点击 **新对话** 开始。选择自己的项目或 Fork，告诉 Agent 要处理的问题和验证方式。每个仓库对话使用独立工作区与贡献分支，基础克隆可以复用。

模型位于输入框右侧，紧邻模式和发送按钮。长名称完整换行。模式为 **Flash、Reasoning、Pro、Ultra**；是否可用取决于模型能力、账号授权和部署配置。当前界面通过模式菜单使用思考与计划能力。

输入消息后发送，附件按钮用于上传资料。可用技能可以通过输入区的引用选择器或输入 `@` 引用；技能导入和管理在设置 → 可选功能 → 技能。

## 执行与结果

执行记录展示实际工具调用。测试是否通过以实际命令输出和回归结果为准。Agent 生成的文件可在文件或产出物面板预览、下载；文件内容与消息历史各自保存。

## Git 审阅与发布

打开 Git 审阅，检查差异与验证结果。保存 PR 信息只在本应用保留目标、标题和说明；推送贡献分支将代码上传到贡献仓库；创建 GitHub 草稿或正式 PR 则会在目标仓库产生真实 PR。

自己的项目可以直接使用，上游可留空。向其他项目贡献时可选自己的 Fork，并把官方仓库作为 PR 目标。草稿 PR 也对目标仓库维护者可见。

## 可选功能

设置 → 可选功能提供工具与集成、技能和扩展目录，以及自定义 Agent 的导入入口。子智能体仍在设置的独立页面新增和编辑。操作受既有权限与服务器配置控制。

原对话从最近对话恢复。删除对话需要确认，请在删除前检查关联的数据与文件。

参阅[Agent 与线程](/docs/application/agents-and-threads)和[快速开始](/docs/application/quick-start)。
